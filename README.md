# \# Music Discovery \& Artist Visibility Dashboard

# 

# \## Overview

# 

# This Business Intelligence project explores music popularity, chart movements, and artist visibility using Spotify chart data and track metadata.

# 

# The goal is to help listeners discover music beyond mainstream hits and provide insights into how tracks and artists perform across regions and over time.

# 

# \## Objectives

# 

# \- Analyze historical music chart rankings and stream counts.

# \- Compare music popularity across regions and dates.

# \- Examine chart movement and track performance.

# \- Enrich chart records with Spotify track metadata.

# \- Prepare structured data for MySQL and interactive dashboards.

# 

# \## Data Sources

# 

# \### 1. Spotify Charts Dataset

# Historical chart records containing track titles, artists, rankings, dates, regions, chart types, trends, Spotify URLs, and stream counts.

# 

# \### 2. Spotify Web API

# Track metadata retrieved using Spotify track IDs, including track names, artists, album names, and release dates.

# 

# \*The suitability of these sources under the course's distinct-source requirement will be confirmed with the instructor.\*
